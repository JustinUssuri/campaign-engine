# 地面与飞行旅行（2026-11-05 玩家确认）

本规则取代日常地面与飞行旅行的快／正常／慢步调及其察觉、生存、隐匿效果。唯一数值来源为 `rules/travel.yaml`；本页解释口径和操作，不另存一套参数。

## 计算口径

标准行进日为八小时旅行时段，包含例行短歇；基准为轻载、健康且适应旅行的骑乘马在坚实畅通道路上每日30英里，因此小时进度为3.75英里。不是战斗Speed换算，也不再引用原快档4英里／小时。每日进度＝30英里×物种×载重×路况。物种：人⅔、马1、骡0.9、驴0.6、骆驼1；四类马使用相同旅行倍率，不改变各自战斗卡。人形主角使用人的旅行倍率；其余未登记形态不猜成马或人，飞行、船行及持续魔法移动仍走各自规则。

载重按实际外载／现有相应上限分档：≤⅓为轻载×1，＞⅓至⅔为中载×0.8，＞⅔至上限为重载×0.6。骑手、乘客裸重及装备、鞍具、容器和货物计入承载者；车自重计入牵引。裸重与钱袋实重沿用形态／现金快照绑定的称重证据，账面钱数不推定实币重量，未知不当零。超载须卸载或增加合法运力，不能靠乘一个小速度合法化。

路况为好×1、差×0.75、很差×0.5。坚实正常的未铺装路也可以是好路；安瑟旧路按好路。砾石、坡道、泥泞、窄道等本段通行难度归入这一个因子，不再同时用原版地形限档或因同一原因减半。不可通车独立于速度：不能用很小倍率把车送过羊肠道。只调整受影响路段。

逐移动单元先计算速度，再取队伍瓶颈；车的乘客不再另作为步行者，套车牲口不重复计成独立驮畜。自己牵行的未套车驮畜仍是自有运输单元。已知慢车必须约束队伍，不能拆开取不同成员的最重载况、最低物种系数再拼成更慢速度。

仍在自身持有链上的独立车辆必须纳入运输安排；清除或改选交通工具不代表停车。先实际停车卸套，才能用 `travel continue --vehicle 无` 改为步行；已停车的工具须显式重新选择才会随行，不凭旧行程选项自动带走。

这是便于自动计算的房规：⅓／⅔、三因子独立、固定物种比均非实测生理定律。只核对了典型日程的量级；中重载马骡的比例差仍固定，骑乘／驮运／拉车共用倍率。基准是行进日，不承诺连续数周每天维持上限。

骆驼倍率及NPC驼队模板已可计算；当前商品目录尚无自有骆驼类型。本次不凭速度系数新增售价或日粮，未来实际取得骆驼时须先登记已核类型、承载卡和补料依据，不能将隔离测试fixture当成正式已有商品。

## 商队

NPC商队只用整队标准行进速度模板，默认正常商业满载且已组织好，不逐车生成库存，也不因货单缺失视作轻载。模板初值参考重载结果：马／骆驼18英里／日、骡16.2、驴10.8；模板替代NPC各自物种与载重计算，不是另加的第四倍率。好路模板只乘本次路况一次；有出处的整队速度若明确已含路况，则不再乘。自有车辆、坐骑、驮畜和自身携带才核实际负荷，其他NPC自有运输不逐件盘点；搭在玩家运输单元上的NPC身体与装备仍须计入。

新开程比较同口径的标准行进速度；已有跟队约定保留。牲口损失、车损、已知慢车或明显换货时，只核受影响单元。整程日历平均数含停车与休整，不能反推出白天巡航速度作为跟队证明。

## 原路线与新距离路线

已登记的 `days`、`minutes`、同源地图分钟，以及已经进行中的旧快照，都是已校准耗时，按原口径执行；它们可能含原路况、装卸、常规停歇和夜宿，绝不再乘物种／载重／路况或另除八小时。船程不套地面倍率。商队模板在旧路线只负责自有运输的跟队预检，不缩放旧总天数。

新增可靠里程的路线使用 `distance_miles`，每段注明 `road` 和 `cart_allowed`。只有实际赶路扣距离；睡觉、停留、战斗和整日休整不扣。开程及续行核实际载况，变更只影响余程；物品和定时收付导致的缺项不得静默沿用旧载况。途中可察觉的世界节点仍截停，玩家明确继续后才续行。

不得未经确认把旧耗时乘新速度倒造距离，也不从近似地图方位锚量出确定里程。玩家另行授权补定的路线，可以将旧行程与地图作设计参考，但必须注明本次新定值、剔除额外停歇且不冒称旧实测。旧行程不回算；新规则可能使未来重载驴运更慢，这是前瞻机制变化，不改历史行程、工资、钱粮或NPC约定。

距离段可另列 `checkpoint`，完成该段才实际抵达；`at`仍是行进区域，睡眠和等候不提前进入下一段。可选 `pause_after: true` 在到点后停一次，继续不重复；`on_foot_only: true` 要求乘员下骑、本人步行牵畜，不允许默认骑乘过羊肠道。携车遇后段禁车，可先到可通前段的终点再停车改驮，未来阻断不等于当前一段不能出发；全程预估仍须明示阻断，不能报告整程可达。

深铜矿已按本次授权补为20＋6＋4＋0.5＝30.5英里，正反全程及独立腿在 `world/journeys.yaml`。往返同一物理距离、同档路况，装矿后载重据实重核。操作命令见下文[行程与补给](#行程与补给)。

## 飞行旅行

本节只调整未来飞行旅行；地面三个倍率和战斗飞速均不变。唯一飞行倍率为 `rules/travel.yaml` 的 `flight.normal_speed_multiplier: 5`，时数共用 `hours_per_day: 8`。公式为有效Fly尺值÷10×5＝小时英里数；不能从地面30英里基准再乘五，也不能把战斗疾走后再乘五。30／60／80／90尺分别为15／30／40／45英里每小时，八小时标准日为120／240／320／360英里。翼龙60尺即约48.3公里每小时、386公里每标准旅行日。

只有一个默认旅行速度，取消步调及其察觉／生存／隐匿效果。每日八小时是包含普通短歇及例行起落的旅行时段；五倍时速作为正常条件下的平均推进口径，不声称每一秒都按此空速直飞，也不是所有现实飞行动物八小时耐力的实证常数。正常短歇不另记分钟；明确搜索、潜行、盘旋侦察、长停留、战斗或休息按实际活动单独计时，不凭慢速自动给检定优势。异常风雨与航线绕障须有现场依据，不新增日常天气／巡航骰，不套地面道路倍率。

陆空赶路共用当前人物已有的当日八小时预算；换形、落地、重新起飞、取消或重开距离行程不清零。默认推进到八小时即停，玩家再决定落地、休整或按既有强行军规则继续；不新增负重疲劳检定。多名独立飞行者同队，以实际瓶颈为准；骑手计入载者外载，不再作为另一种旅行速度拖慢队伍。

地面距离行程进行或暂停期间，起飞后也不能用普通 `advance --as 赶路` 消耗地面余程或触发地面抵达点。改飞先取消该地面行程，再按实际飞行方式推进；取消保留当天已经使用的陆空共用额度。

外载起飞和持续飞行均不得超过通用承重的一半；骑手裸重、双方装备、鞍具、容器与内容、实物钱袋全部核定，未知不当零。限内不按负重减速，不增加休息或疲劳档位；超限不能靠慢飞放行。该上限与限内默认速度都是游戏简化，不宣称重载没有生理代价或已经验证龙的功率、失速速度。地面载重的⅓／⅔及0.8／0.6倍率不得再套在飞行上限上。

持续飞行效果按当前有效飞速估算，只按实际持续时间执行，不能把十分钟飞行法术直接算成整日航程。只读 `flight speed [人物] [--form 已登记主角形态] [--miles 距离英里]` 查时速、日里程和条件估时；预测形态只能查已登记的主角形态，不实际变形，读速度或估时不等于已核准起飞。实际执行仍用 `flight start` 核完整外载，再按既有 `move`／`advance --as 赶路` 推进，途中事件照常截停。现有 `travel start` 地面／船行路线不因此变成自动空中路线；跨日须按玩家决定实际落地、休息、再起飞，不自动在空中睡觉或变形。

旧航程、已经包含停歇的总日程及已开程快照保持原口径，不直接除以五，不用新速度倒造距离。新飞行估时仅可用有出处的直线／实际航线里程；公开地图的近似锚只供近似规划，不能据此填成确定的 `distance_miles` 自动路线。德尔齐默估距参考见 `world/routes.md`，没有因本次规则改变而产生新的角色测绘知识。

## 行程与补给

已定路线用 `routes` 或 `map route 甲>乙`，草稿补查可用 `turn more --route`。沿有尺度的城图量出的用图上数值，只有近似锚点的标近似。

出发前只读 `travel estimate [路线ID] [--vehicle 车或牲口] [--rider 同乘人物，可重复] [--on-foot] [--road 好|差|很差] [--caravan horse|camel|mule|donkey]`；不写路线只估当前运输速度。指定vehicle默认塔莉娅也在车上／坐骑上，牵车、牵畜驮货时加 `--on-foot`，只把显式rider作为乘员。NPC自己运载不盘点，但坐她车／牲口的人须计裸重和全套装备；不会因名字在同行名单就自动坐上去。缺身体／钱袋实重用 `turn do travel weigh 人物 --body-lb 数值 --cash-lb 数值 --source 核定依据` 登记，可只核缺的一项；沿用flight的形态和现金快照证据，不把账面钱数换成实币，不用旧轻装总重代替裸重。只读预估不补数据、不推进时间。

`routes [ID]` 查已登记路线，`journey` 查当前进度。`travel start ID [--with 人物,…] [--vehicle 实例ID] [--rider 人物] [--on-foot]` 开始并推进；默认只带塔莉娅，已说定的同伴用 `--with`，其余在场者先leave；`travel continue` 只在玩家明确授权后续行；`travel cancel --why 原因` 留在实际位置。途中遭遇截停，保留余程，不在一回合里继续推进。续行可显式更新vehicle、rider、on-foot和当前段road；`--vehicle 无`／`--rider 无`清除相应运输安排，停车、卸套或改变乘坐须已落实，不自动挪车或替旁人作决定。路线来源、已说定同行及位置仍须先核实，不自动报名商队、付钱、借牲口或移走旁人。

长途作息、伙食沿用已登记路线routine，缺少时一次指定 `--rest-start 21:00 --rest-hours 4 --rest-as 出神 --food 自备 --source 已说定出处`；距离路线可登记routine.travel_start，确定每天开始赶路时间，不替玩家决定睡觉或变形。乘船须已经登船，另写 `--vessel 船地点ID --departure 起点ID --source 本次出发出处`；不是订票、装车或付费。七至八天等范围只在开程时掷一次，换会话不重掷，角色只知原预计。

每满24小时按约定扣各人自己的干粮，船上牲口按无草扣料；不暗借同伴口粮、不自动购物。缺粮／草停在结算边界等玩家决定。到达船程终点仍在船上，尚未卸车或替玩家选去处。

同行不产生代付授权。买干粮、住宿默认只买塔莉娅的份，替同行者采买或供餐须有明确约定，各人的实际支出分别登记。登记路线以自有干粮或已约定供餐办理。普通 `advance --as 赶路` 和野外过夜目前按合计日需扣前台粮，不会自动从同伴自备粮扣。若同伴各自供餐或用自备粮，先核吃饭和支出归属，用 `--eaters N` 指定实际由这份库存负担的标准天份，明确另食可用 `fed`。旧动作和旧账不追算。

- **野外过夜吃干粮、草料**：推进跨过半夜时她在野外（不在城镇、村子里），干粮照塔莉娅＋在场NPC扣，赶路已扣不重复；别人管饭／吃别的用 `fed --by 谁 | --with 物品 [--qty N]`。牲口按类型日粮×有效供给补料比例结算（足×0、少×½、无×1；未登记普通草况按少）。驴每日1份、骡1.8份、役马／骑乘马2份、挽马／战马2.2份；一份10磅优质干草，基础价3cp，当地倍率照物价表。世界层原有区域可按季节登记普通草况和可选粗饲；耐粗饲仅让驴骡使用其实际可利用供给，无资料不自动优惠，不加每日骰或采食时数账。船上自动全补；本段明确无采食机会时，普通 `advance` 或 `travel start` 加 `--no-grazing`（非日常必填；普通advance须在触发该日补料结算的推进上带此标志，白天短动作不另登记全天禁牧；登记行程持续采用该次设置）。从与牲口同处的库存扣，缺料列明；野外过夜、赶路和登记行程的预检／实扣同一口径，不追改已结算日。
- **赶路扣干粮**：`advance --as 赶路` 默认合计塔莉娅＋在场NPC的日需量（狗头人每只½标准天份，塔莉娅与其他现有族群仍1；野外过夜同用），同日不重复扣。新狗头人沿既有规范用 `npc-kobold-…` 登记，耗粮不按显示名猜种族；主角变形不改变既有耗粮口径。同行里有人另有伙食（如押银契管饭，E1873：塔莉娅、雷蒙德吃银号的伙，只米拉吃干粮），这一路每次 `--as 赶路` 都要写 `--eaters N`；N是实际需扣的标准天份总量，可写0、0.5等，最多两位小数，不再把狗头人人头数直接填进去。先看最近的裁决里定过谁吃干粮，再合计份量（E1900 漏写多扣2天份，玩家指出）。登记行程的自备粮按各人日需量检查，不暗借同伴口粮；半份不足也停在原补给边界等玩家裁定。

## 载具、坐骑与外载

- **骑乘、驮载、拉车先查对应卡**：驴 `rule Donkey`、骡 `rule Mule`、役马 `rule Draft Horse`、挽马 `rule Cart Horse`、骑乘马 `rule Riding Horse`、战马 `rule Warhorse`。驴中型，仅小型能骑；其余大型可供中型骑手。**能驮多少、车能拉多少只看 `items 名字`（或 `turn more --items`）附的数值**，不信物品名或旧裁决里的固定数字（E2689–E2690加帮套未更新车名）。类型表提供卡，实例不另存卡值；骡与役马已拆卡，旧 `draft-horse` ID继续表示役马，新增挽马不可按旧称自动替换。稳步只在松石、湿滑、崎岖落脚风险的检定／豁免标优势；耐粗饲按实际可食植物与采食机会判断，均仅驴骡拥有。骑乘马舒适不免疲劳；受控战马仍只能疾走／撤离／闪避，独立行动时的冲锋按卡裁定，不自动赠骑手攻击。修改马匹力量或速度仍须核实代表体格、工况及规则映射，不用平均值或用途名称代替证据（2026-11-05）。

- **车和牲口**：车记着常用牲口（`edit-item 车 --team 晨星,书签`）。出门 `put 车 --to 塔莉娅`：常用牲口在车边的都套上，车连牲口、车上的东西一起跟她走，【场面】列“带着：车（套谁；合计/能拉 磅）”；不在车边的引擎摆出它在哪——对一遍再写。短停（装卸、进铺子）让车留在人手上（`put 车 --to 雷蒙德`）；过夜、到地方、正午长歇 `put 车 --in 地点 --team-spot 驴棚` 停车卸套（现实：带着挽具过夜会磨伤，牲口躺不下、吃不了草）。单牵一头 `put 晨星 --to 谁`。车上不去的路驮着走：`put 行囊 --in 晨星`。**世界层的人动了她的东西**（牵走、牵回、拿走）由 world-planner 写 挪，引擎下次推进挪进存档，“幕后”一行给主持看；游戏里当面发生的照常 put（E3119：书签 D320 被牵回铜杯只写在供词卡里，存档一直记在深铜矿）。

飞行外载用 `flight [人物] [--rider 人物]` 先查。上限一律为该形态通用承重的一半，骑手裸重、双方随身装备、鞍具、容器及内容、钱袋和行李全部计入，按实际 `in` 所在位置计，不按所有权猜行李在哪里，也不因变形自动免除装备重量。次元容器按已登记的免内容重量规则计算壳重。地面驮运与拉车保持原规则。

只读巡航查询用 `flight speed [人物] [--form 已登记的塔莉娅形态] [--miles 距离英里]`。当前形态显示默认时速、八小时里程与完整外载能否执行；`--form` 仅预测主角已登记形态的速度，不实际变形、不批准起飞。指定里程须有出处，地图近似估距只报近似旅行小时，不登记为确定路线。实际飞行与地面赶路共用当天八小时旅行时段，包含普通短歇和例行起落；到点停下，不替玩家强行军、落地或睡觉。

起飞写 `turn do flight start 人物 [--rider 人物]`（多个骑手重复 `--rider`），落地写 `turn do flight land 人物`；战斗 `go --by 飞` 及初始高空飞行 `pos` 同样检查，站在高台用 `pos ... --by 走` 明示支撑。持续飞行在每个动作、定时钱物变更步骤及时间推进后重核，换形态、拿取物品、现金变化不会沿用旧核算；超限或缺项会拒绝动作。战斗下降到地面后再 `flight land`，不能在高处直接清掉飞行状态；脱战后该动作表示实际降落，仍须先通过完整载荷检查，再同步已知位置落地。现有 `travel` 登记路线只有地面／船行，空中用起飞后的 `move`、`advance`，不能套用地面行程绕过检查。

裸重与钱袋实重缺失时，先据实核定 `turn do flight weigh 人物 --body-lb 磅 --cash-lb 磅 --source 核定依据`（两项可分别登记；确实没有现金也要明确 `--cash-lb 0`）。裸重证据绑定当前形态，钱袋证据绑定随身现金账的余额快照；金额不等于钱币实物重量，余额变化后重新核定。物品缺重量则核定它的专属类型 `lb`，明确零重量合法，未知／非法数值不能当零。旧回溯的190磅是连同部分装备的总口径，不是可直接登记的裸重。没有高度记录的飞行不能越过失去飞行能力的时点；先在到期前明确落地，不默认从零高度安全降落。

## 长途高空巡航

先按原flight start完整核载并合法起飞，再`turn do flight cruise [人物] --to 地点`进入高空巡航；正常长途默认用这一模式。普通短途和战斗起飞不用。目的地只作为计划，起点旧锚不算仍在那里。

按既有advance赶路和共用八小时推进，效果/载荷/世界时间照常。途中不套地面遭遇、传闻、地面现场或到访反应；只带已经明确且合法飞行/搭乘者，起点旁人不随行。

玩家选择接近时，先核本次已走时间和位置依据，`flight approach [人物] --at 地点 --source 依据`；仍在空中，只看实际可见的外部景象。实际降落用支持明确落地点的flight land；巡航后不能默认落在起点或计划终点。定位不代替赶路/降高耗时。继续前进会使旧落地点核定失效。

八小时/午夜/效果/风险截停就停，玩家再决定；不自动落地、换形、睡觉或次日起飞。临时落脚只补眼前现场。旧锚不能免扣旅途补给。巡航不能消除已生效状态、追击或已经发生的风险。
